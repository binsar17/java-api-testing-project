# Java API Testing Project

Project ini merupakan aplikasi **Mini Banking REST API** berbasis Java Spring Boot yang digunakan sebagai project portfolio untuk **Software Quality Assurance, API Testing, Database Testing, dan Performance Testing**.

## Tech Stack

- Java
- Spring Boot
- Maven
- MySQL
- REST API
- Postman
- Apache JMeter
- Git & GitHub
- IntelliJ IDEA
